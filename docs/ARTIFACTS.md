# Artifact inventory and provenance

## Performance curve

`artifacts/performance/full-indexer-curve/` contains the selected eight points:

- C1, C5, and C10 resident TP4;
- C15, C20, C25, C30, and C32 TP4 with lazy vLLM simple DRAM offload;
- `validation-report.json`, generated by the included validator.

Every run directory preserves:

- the aggregate benchmark JSON;
- `aiperf_artifacts/profile_export.jsonl` request-level records;
- `benchmark_command.txt` and `vllm_command.txt`;
- `run-metadata.txt` with source, image, model, cache, scheduler, and policy
  configuration;
- `console.log` and `server.log`, used to verify replay exit status, GPU faults,
  and post-profile JIT events.

The C15 v23 rerun is authoritative. The superseded v19 C15 run was not copied
into this bundle.

## Correctness

`artifacts/correctness/gsm8k-full-k4/` is the complete real-target EAGLE3 k=4
GSM8K evaluation, including all 1,319 sample records. It is intentionally
separate from the synthetic-acceptance performance curve.

## Profile

`artifacts/profile/` contains the repaired long-context trace summary and exact
server command. The multi-gigabyte raw PyTorch trace is omitted; the summary
retains categorized kernel time and per-rank accounting.

## Public comparison inputs

- `artifacts/b200_reference.json` preserves the matched B200 reference used by
  the acceptance tooling.
- The plot script pins InferenceX Actions runs `31558297538` for the public
  MI355X curve and `31833401868` for B200.

## Exclusions

The source experiment tree is approximately 5.8 GB. This repository excludes
superseded diagnostics, invalid correctness runs, failed warmup iterations,
duplicate C15 artifacts, and raw multi-gigabyte traces. The curated files are
the minimum set needed to audit the accepted curve and correctness claim.

No model weights, private trace payloads, credentials, SSH material, or access
tokens are included.
